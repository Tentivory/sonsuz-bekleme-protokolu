# Sonsuz Bekleme Protokolü

## Giriş: Beklemenin Felsefesi

Sevgili insanlık,

Bu depo, evrenin en temel yasasını kod haline getirmektedir: **BEKLEMEK**. 

Diğer depolar size hızlı sonuçlar verir. Bu depo ise size gerçeği verir: Sonuç gelmez. Çünkü beklemek, hayatın kendisidir. 

### Nasıl Çalışır?

1. `python bekle.py` komutunu çalıştırın.
2. Bir sayı girin.
3. Protokol, o sayı kadar saniye boyunca sizi bekletir. Bu sürede derin felsefi mesajlar alırsınız.
4. Sonunda anlamsız bir cevap alırsınız. Tıpkı hayatta olduğu gibi.

### Neden Bu Protokol?

Çünkü herkes acele ediyor. Kimse beklemiyor. Ama bekleyenler kazanır. Ya da kaybeder. Ya da hiçbir şey olmaz. Bu protokol, o "hiçbir şey"i kutlar.

**UYARI:** Bu protokolü çalıştırırsanız, zamanınızı geri alamazsınız. Tıpkı gerçek hayatta olduğu gibi.
